Clean from AIBrowser extension · X · Typefully

Privacy Policy

Effective 14 October 2026 · v2.4.0

Clean from AI removes hidden AI watermark characters and AI-style typography (long dashes, curly quotes, fancy Unicode letters) from the posts you write on X and Typefully, and from any text you paste into the extension's popup.

No data leaves your browserThe extension has no network code at all. It never sends your text, your settings or anything else to a server. There is nothing to collect, so nothing is collected.
Nothing is stored except two settings and a numberYour browser's extension storage keeps which cleaning rules are on, whether the extension is paused, and a running count of characters it has cleaned. The text you clean is never saved.
It only reads what you are typingOn x.com and typefully.com the extension reads the contents of the post editor you have clicked into, so it can show how many AI tells are inside and clean them when you ask. It does not read other people's posts, password fields, direct-message history, cookies or your clipboard.

Permissions

  • storage — to remember your settings and the counter described above.
  • Access to x.com, twitter.com and typefully.com — to add the Clean AI button to the post editor on those sites only.

Third parties

None. No analytics, no trackers, no fonts or scripts loaded from external servers, no dependencies. Everything the extension needs is inside the package you install.

Open source

The complete source code is public, so every claim on this page can be checked: github.com/Handsher/clean-from-ai. A security review of the current version is in SECURITY-AUDIT.md.

Changes and contact
